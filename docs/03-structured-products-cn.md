# 03 · 中国场外结构化产品（课程很少系统讲）

国内投资者接触最多的往往不是交易所香草，而是**银行理财 / 券商收益凭证 / 场外期权**里的结构化条款。本库覆盖几类典型积木；真实产品是积木的组合。

## 1. 先建立「拆解思维」

几乎所有收益凭证都可以拆成：

```text
债券（或存款） + 期权组合（香草 / 障碍 / 二元） ± 参与率 ± 票息
```

定价时不要死记产品名字，要问：

1. **什么时候拿本金？** 是否保本 / 部分保本  
2. **观察什么？** 收盘价、均价、盘中是否算  
3. **触发后拿什么？** 固定票息、敲出即终止、还是变成另一段期权  
4. **参与率多少？** 收益是否封顶  

## 2. 鲨鱼鳍（Shark Fin）

### 2.1 直觉 payoff（单向向上看涨常见形态）

- 标的未触及上障碍：按参与率分享上涨（类似 call）  
- 触及上障碍：期权敲出，投资者拿**固定敲出收益 / 票息**  
- 有时还有保底收益 `floor`

形状上像「鲨鱼鳍」：中间翘起，过高则被「切掉」。

### 2.2 本库对应

| 函数 | 角色 |
|------|------|
| `up_and_out_call` | 解析风格：向上敲出 + 参与率 + 保底 |
| `shark_fin_option` | MC 风格演示版（触及上障后按香草结算，**条款简化**） |

> 重要：两个函数**不是同一套条款**。`shark_fin_option` 更适合理解路径模拟；`up_and_out_call` 更接近教科书障碍分解。读发行说明书时，以条款为准，不要直接拿任一函数当「行业标准鲨鱼鳍」。

### 2.3 实务要点

- **障碍观察**：多数产品用交易日收盘价，少数含盘中  
- **期初价格**：可能是期初均价（2–5 个交易日）  
- **敲出后是否提前终止**：影响贴现与对冲  
- 高票息产品往往靠**更紧的障碍 / 更低的参与率 / 更短的期限**换来

## 3. 敲入 / 敲出与「雪球」类（概念对照）

本库实现了敲入看涨等积木。市场热门的「雪球」通常是：

```text
一系列敲出观察 + 向下敲入（变成看跌风险）+ 票息
```

雪球**不是**简单 `down_and_in_call`。但学习路径建议：

1. 先搞懂单障碍敲入/敲出解析结构（`knock_in.py`）  
2. 再叠加「多个敲出日 + 票息累进」→ 几乎必然走 MC  
3. 风险点在敲入后的**卖方敞口**与流动性，不在公式漂亮

## 4. 安全气囊（Airbag）

名字营销感强，条款因机构而异。常见叙事：

- 上涨：有参与  
- 下跌未破气囊线：保护或缓冲  
- 跌破后：保护减弱，可能线性承担亏损  

本库 `airbag_option_price` 采用简化组合：

```text
参与率 × (香草看涨 + 向下敲入看跌)
```

这是**教学用结构近似**，不是某家银行的标准气囊。用之前先对照条款：有没有封顶、是否用均价、敲入后是否变成看跌空头。

## 5. Range Accrual（区间计息）

逻辑极简、实现却很「交易日」：

```text
计息天数 = 标的收盘价落在 [L, U] 内的交易日数量
价格 ≈ e^{-rT} × E[计息天数] × (单位日收益)
```

本库 `range_accrual_price` 返回的是「计息天数期望的贴现」，**没有再乘日票息**。若产品写「每日计息 3% / 365」，需要再乘票息因子。

实务坑：

- 开区间还是闭区间（`>` / `>=`）  
- 节假日是否观察  
- 是否提前敲出终止计息  

## 6. 二元与「固定收益腿」

现金或无、资产或无常作为：

- 敲出票息的近似零件  
- 数字期权嵌入结构  

见 `derivatives.pricing.binary`。报价时注意：二元的 Delta 在行权价附近极尖，对冲成本高——**卖方不会按解析 Delta 无摩擦对冲**。

## 7. 读条款的检查清单（可打印）

- [ ] 标的：个股 / 指数 / 篮子 / 最差表现  
- [ ] 期初价：单日还是均价  
- [ ] 观察：收盘 / 连续 / 是否有障碍窗口  
- [ ] 敲入敲出水平：绝对点位还是期初价百分比  
- [ ] 参与率、封顶、保底、票息  
- [ ] 提前终止规则与兑付日  
- [ ] 名义本金与费率（前端费是否已进价格）  
- [ ] 是否可赎回 / 发行人调用  

## 8. 建议的动手项目

1. 把 `up_and_out_call` 的参数扫一遍：障碍从 105% 到 130%，画价格曲线。  
2. 用 MC 自己实现「日终观察的向上敲出 + 固定 rebate」，与解析连续障碍对比。  
3. 找一份公开产品说明书，列出上表检查清单，标出本库能/不能覆盖的部分。
