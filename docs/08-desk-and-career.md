# 08 · 交易台与从业视角（课程几乎不讲）

本章把「会写定价公式」放到真实分工里：谁关心价格、谁关心风险、你还缺什么。

## 1. 一条结构化产品大概怎么走

```text
销售 / 渠道收集需求
    → 结构师设计条款（票息、障碍、期限、参与率）
    → 量化定价 + 对冲成本 + 利润垫
    → 风控限额 / 合规 / 适当性
    → 发行或与客户成交
    → 交易台动态对冲与簿记
    → 到期清算 / 敲出提前终止
```

研究脚本通常只覆盖中间「定价」一小段；**对冲成本与利润垫**才决定能不能卖。

## 2. 角色与技能

| 角色 | 更看重 |
|------|--------|
| 衍生品销售 | 条款翻译、客户风险承受、竞品票息 |
| 结构师 | 收益图、成本拆解、监管约束 |
| 量化定价 | 模型、校准、快速报价、验证 |
| 交易 / 对冲 | Greeks、流动性、情景、过夜风险 |
| 风控 | 限额、压力测试、模型验证、文档 |

本仓库最贴近「量化定价 + 研究」轨道；若目标是交易台，还需补：期货微观结构、席位与保证金、盘中风险管理。

## 3. 面试常被追问（超出作业题）

1. 为什么股指期货长期贴水？对期权定价有何影响？  
2. 连续障碍与日终障碍价格谁高？为什么？  
3. 如何用香草大致对冲一个敲出结构？残余风险是什么？  
4. MC 估计的置信区间怎么报？路径数如何定？  
5. 波动率上涨时，向上敲出看涨一定更贵吗？  
6. 讲一次你查过的定价 bug：现象、根因、回归测试  

建议用本手册第 03–07 章的语言回答，并落到你跑过的 `examples/` 数字上。

## 4. 自学地图（实践向）

### 必做项目

1. **迷你定价库**：香草 + 单障碍 + MC，带测试（本仓库已是雏形）  
2. **参数流水线**：从 CSV/Wind 拉 S、F、估 q、估 HV，自动生成报价表  
3. **条款翻译器**：输入说明书要点 → 输出 payoff 伪代码  
4. **对冲模拟**：每日 Delta 对冲香草，统计对冲误差分布  

### 加分项目

1. 局部波动率或简单随机波动率，看障碍价格变化  
2. 雪球类离散敲出 MC + 情景分析  
3. 把 Greeks 做成监控仪表（距障距离、Vega 集中度）  

## 5. 职业早期建议

- **正确性 > 炫技模型**：先保证 BSM/parity/回归测试，再上复杂模型  
- **会写文档**：条款假设写不清，等于模型不可交接  
- **尊重数据**：脏数据、错误合约乘数、错位的除权，比公式错误更常见  
- **懂一点会计与监管语言**：名义本金、风险等级、投资者适当性会影响「能不能卖」而不只是「算多少钱」  

## 6. 如何继续扩展本仓库

优先级建议：

1. CI：每个 PR 跑 `pytest`  
2. 校准模块：从期权行情反解 IV  
3. 产品层：用配置文件描述鲨鱼鳍/气囊条款，而不是改函数参数  
4. 报告：一键输出价格、Greeks、压力情景  

## 7. 结语

课程教会你在理想世界算一个数字；实务要你在**不完美数据、不完美对冲、不完美条款翻译**里，仍然给出可解释、可复现、可风控的价格。

从下一笔练习开始：固定 seed，写清假设，留下测试。这比再推导一个公式更接近真正的量化工作。
