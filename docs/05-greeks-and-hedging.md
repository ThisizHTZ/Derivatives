# 05 · Greeks 与对冲实务

会算 Delta 只是起点；交易台关心的是：**今天对冲多少、明天会不会爆、障碍附近怎么办**。

## 1. 本库 Greeks 含义

```python
from derivatives import compute_greeks
g = compute_greeks("C", S=100, K=100, sigma=0.2, T=1, r=0.05, b=0.05)
```

| 字段 | 含义 | 实务习惯 |
|------|------|----------|
| `delta` | ∂V/∂S | 对冲股数 / 名义比例 |
| `gamma` | ∂²V/∂S² | Delta 变化速度 |
| `vega` | ∂V/∂σ | 常除以 100，报「每 1% vol」 |
| `theta` | ∂V/∂T（本实现按解析式） | 常报每日 theta ≈ 公式/365 |
| `rho` | ∂V/∂r | 利率不敏感产品可粗看 |

`b` 的选择会改变整组 Greeks（期货期权 `b=0` 与股票 `b=r-q` 不同）。

## 2. Delta 对冲：理想公式 vs 现实摩擦

理想：持有 `-Δ` 份标的，组合瞬时无风险。  
现实：

- 买卖价差、印花税、冲击成本  
- 涨跌停无法调仓  
- 指数用期货对冲还有**基差风险**  
- 离散对冲 → 留下 Gamma/Theta 博弈  

经验：

- 高 Gamma（平值短期）→ 对冲频率要高，成本高  
- 深虚值长期 → Delta 小，但事件日可能一夜翻脸  

## 3. Vega：结构化卖方的主风险之一

障碍、二元、鲨鱼鳍对波动率极敏感。实务上会：

1. 用期权/波动率产品对冲 Vega  
2. 或在簿记限额内「吃」Vega，用价差补偿  
3. 关注 **skew**：下障产品更吃 downside vol  

常数 σ 模型的 Vega，只能当一阶指示，**不是曲面风险的全部**。

## 4. 障碍附近：Greeks 会「发疯」

接近敲出/敲入障碍时：

- Delta 可能剧烈变化甚至变号  
- Gamma / Vega 尖峰  
- 离散对冲误差放大  

这就是为什么：

- 连续监控解析解好看，但日终监控产品要用离散模型重估  
- 风控会对「距障碍几个点」设单独限额  

## 5. 组合簿记视角（课程少讲）

单笔定价对了，簿记仍可能亏：

| 风险 | 来源 |
|------|------|
| 方向性残留 | Delta 对冲不及时 |
| 波动率 | Vega / Vanna / Volga |
| 基差 | 用期货对冲指数期权 |
| 相关性 | 篮子 / 最差表现结构 |
| 流动性 | 急跌时无法调仓 |
| 模型 | 用错监控假设、用错分红 |

卖方最怕的不只是「算错价格」，而是**同类结构同向累积**（例如大量近障雪球）。

## 6. 用本库做 Greeks 实验

```bash
python3 -m examples.greeks_plot
```

建议自己改：

1. 缩短 `T`，看 Gamma 尖峰  
2. 比较 `b=r` 与 `b=r-q` 的 Delta 差  
3. 对障碍产品用 bump-and-reprice 估数值 Delta，对比平滑香草

Bump 示例思路：

```python
eps = 1e-2
# price_up = f(S+eps); price_dn = f(S-eps)
# delta_num = (price_up - price_dn) / (2*eps)
```

MC 产品做 bump 时务必**共用随机数（common random numbers）**，否则数值 Greeks 全是噪声。
