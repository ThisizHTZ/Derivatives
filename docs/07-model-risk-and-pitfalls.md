# 07 · 模型风险与常见坑

这份清单来自教学代码与实务交接里最常见的翻车点。

## 1. 本库已修过 / 需警惕的历史坑

| 坑 | 表现 | 正确做法 |
|----|------|----------|
| Greeks 看涨只返回 rho | 字典残缺 | `compute_greeks` 统一返回全字段 |
| 安全气囊变量叫 put 却算 call | 结构语义错 | 看组合定义，不看变量名 |
| 股息率写成 `q=2` | 价格荒谬 | 小数 0.02 |
| 基差结果选了空列名 | 运行报错 | 使用明确列 |
| `main.py` 重复定义函数 | 后定义覆盖前者 | 包内单一实现 |
| MC 无 seed | 无法复现论文/作业 | 传 `seed` |

## 2. 符号与单位

- `sigma=20` 当 20% → 实际当成 2000%  
- 障碍用百分比 `1.2` 却对现货 `100` → 应统一为 `120` 或全程用相对价格  
- 敲入函数里 `K` 是 rebate，不是行权价——**读 docstring**  

## 3. 把「产品名」当成「唯一公式」

鲨鱼鳍、气囊、雪球在不同机构条款不同。  
风险：用教学函数直接报价。  

对策：先画 payoff / 现金流时间线，再选积木。

## 4. 监控假设不一致

- 解析：连续  
- 合同：日终  
- 回测：用了最高价  

三者混用会导致「回测很赚、实盘触障」。

## 5. 分红 / 基差忽略

指数长跑产品、深度实值期权、障碍靠近现价时，`q` 误差会被放大。  
负基差阶段用 `q=0`，往往系统性偏贵/偏便宜（方向取决于 call/put 与结构）。

## 6. 对冲与定价模型分裂

定价用 BSM 常数 σ，对冲却按主观「感觉」调仓；  
或定价用期货隐含分红，对冲用现货忽略基差。  

簿记要求：**定价假设与风险报告假设尽可能一致**。

## 7. 过拟合随机数

调参直到 MC 打出「想要的」票息价格。  
没有 seed 控制与置信区间时，这是假精度。

## 8. 数值稳定性

- `T→0`、`σ→0`、障碍极近 `S` 时，公式里 `log`、`λ` 可能不稳  
- 级数型双障碍：`max_iterations` 不够会偏；过大则慢  
- 美式树步数与内存：`O(steps²)`
