# 04 · 参数与行情（定价误差的真正来源）

模型选错会偏；**参数取错会废**。课程给定数，实务要自己挖。

## 1. 波动率：历史 vs 隐含

| 类型 | 怎么来 | 适合 |
|------|--------|------|
| 历史波动率 HV | 收益率标准差 × √252 | 研究、回测、无期权市场标的 |
| 隐含波动率 IV | 从期权市价反解 | 有流动性的期权（50ETF、部分商品） |
| 波动率曲面 | IV(K,T) | 做市与障碍产品（需插值） |

### 1.1 历史波动率速算

```python
import numpy as np
# closes: 收盘价序列
log_ret = np.diff(np.log(closes))
hv = log_ret.std(ddof=1) * np.sqrt(252)
```

窗口怎么选？

- 20 日：更贴近近期，噪声大  
- 60–120 日：更稳，反应慢  
- 事件（财报、政策）前后 HV 会跳——**障碍产品对跳变极敏感**

### 1.2 隐含波动率注意点

- 用哪一档行权价？ATM？25Δ？  
- 期限是否匹配产品到期？  
- 指数期权与个股期权流动性差异巨大  

本库目前吃的是**单一常数 σ**（BSM 世界）。把曲面压成一个数时，请在报告里写清：用了哪天、哪一档、是否做过期限匹配。

## 2. 股息率与股指「隐含分红」

个股：可用预期分红贴现近似 `q`。  
指数：成分股分红参差，实务更常用**期货基差**反推：

```text
F = S * e^{(r - q)T}
⇒ q = r - (1/T) * ln(F / S)
```

等价地，年化基差率与「现货相对期货的便宜程度」相关。本库 `compute_basis_rates` 对中证500样例数据计算：

- `annualized_basis_rate`
- `custom_moving_avg_basis_rate`（约 20 日移动平均）

```bash
python3 -m examples.basis_rate
```

解读时记住：

- **负基差**（期货贴水）在 A 股股指上很常见，隐含 `q` 可能偏高  
- 临近交割、移仓期，基差噪声大——移动平均是为了平滑  
- 用近月还是次近月期货，结果会不同

## 3. 利率曲线：一个 `r` 的局限

短期限产品用单一 `r` 够用；拉长到 1–3 年，应：

1. 取对应期限国债 / 互换利率  
2. 或对现金流分段贴现  

结构化产品若含发行人信用，严格说要用**含信用利差的贴现**——教学库通常忽略，但报价时不会忽略。

## 4. 行情源：Wind 与其他

`derivatives.integrations.windlink` 仅封装启动：

```python
from derivatives.integrations.windlink import start_wind
w = start_wind()  # 未安装 WindPy 则返回 None
```

实务取数清单（示例）：

| 数据 | 用途 |
|------|------|
| 指数点位、成分 | 标的现价 |
| 股指期货连续/主力 | 基差、隐含分红 |
| 期权隐含波动率 | σ |
| 国债收益率 | r |
| 交易日历 | 观察日序列 |

没有 Wind 时：交易所官网、Tushare、AKShare 等也可搭研究环境，但**生产对账仍以牌照数据源为准**。

## 5. 参数进模型前的「卫生检查」

- [ ] `S, K, H` 同一量纲（点位 vs 百分比）  
- [ ] `T > 0`，且与观察日个数一致  
- [ ] `sigma` 是年化小数（0.2）不是 20  
- [ ] `q` 与 `b` 不要重复减息  
- [ ] 障碍在合理区间（如 70%–130% 期初），极端参数先画 payoff  
- [ ] MC 固定 `seed` 后再调参对比  

## 6. 课程外练习

1. 用同一指数，分别取 20/60/120 日 HV，看鲨鱼鳍价格差多少。  
2. 用基差反推 `q`，再代入 BSM，与 `q=0` 对比。  
3. 人为把 σ 从 15% 扫到 35%，记录障碍产品价格是否单调——若不单调，检查条款拆解是否合理。
