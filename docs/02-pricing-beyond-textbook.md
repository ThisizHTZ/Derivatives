# 02 · 定价实践：课本之外

教材给连续时间、连续复利、完美市场；实务先解决：**时间怎么数、钱怎么折、标的到底付不付息**。

## 1. 时间 `T` 不是「剩几个月 / 12」那么简单

| 惯例 | 常见用途 | 例子 |
|------|----------|------|
| Actual/365 | 国内场外、研究脚本 | `T = days / 365` |
| Actual/365F 或 360 | 利率产品 | 需看合约 |
| 交易日年化 | 波动率估计 | `sigma_daily * sqrt(252)` |

结构化产品常写「观察日为交易日」。定价时：

- **到期时间**：可用日历日 / 365  
- **路径步数**：更合理用交易日数（如 240–252）  
- 两者混用时，要在笔记里写清楚，否则复现对不上

本库 `Range Accrual` 默认 `trading_days=240`，就是按「一年约 240 个交易日」的实务近似。

## 2. 利率 `r`：无风险到底用什么

课程常写「无风险利率 r」。实务可选：

1. **国债收益率曲线**（按期限插值）——偏「无信用风险」  
2. **银行间回购 / 存款利率**——偏资金成本  
3. **发行机构融资成本**——做市商内部定价更常用  

对短期 OTC 结构，用错 50bp 可能不如波动率错 1% 致命，但**组合账本上利率风险要统一曲线**。

本库假设 **连续复利**。若你手上是年复利 `R`，近似转换：

```text
r_cont ≈ ln(1 + R)
```

## 3. 持有成本 `b`：一张表记牢

| 标的 | 常见设定 | 本库写法 |
|------|----------|----------|
| 不付息股票 / 简化 | `b = r` | `black_scholes_merton(..., q=0)` |
| 连续股息 `q` | `b = r - q` | `q=...` 或 Greeks 里传 `b` |
| 股指（用期货隐含分红） | `q ≈ r - (1/T)ln(F/S)` | 先估 `q` 再代入 |
| 期货期权（Black76 思路） | `b = 0` | Greeks / 树里 `b=0` |

常见错误：指数现货用 `q=0`，却拿期货价格当现货——**基差被忽略，障碍产品偏差很大**。

## 4. 欧式 vs 美式：什么时候必须换模型

| 类型 | 能否提前行权 | 推荐 |
|------|--------------|------|
| 欧式 | 否 | BSM / MC |
| 美式股票看跌 | 是 | 二叉树 / PDE / LSM |
| 美式看涨（无股息） | 理论上不应提前 | 仍可用欧式近似 |
| 美式看涨（有股息） | 可能提前 | 二叉树更稳妥 |

本库 `american_option_tree` 用的是 CRR 风格树 + 每节点取 `max(继续持有, 内在价值)`。

## 5. 解析解、树、MC：怎么选

```text
香草欧式、连续股息          → 解析解（快、准、可对冲）
美式、路径依赖弱            → 二叉树 / PDE
障碍监控复杂、多资产、条款怪 → 蒙特卡洛
需要 Greeks 曲面            → 解析优先；MC 用有限差分估 Greeks 很吵
```

经验法则：

1. **能解析就解析**，MC 做交叉验证  
2. 障碍 + 离散监控 → 解析解（连续监控）与 MC（日终）可能差几个点，这是**模型差异**不是 bug  
3. 二叉树步数太少会振荡；对照 BSM 时至少几百步

## 6. 贴现与 payoff 的「结算货币」

定价公式默认：payoff 以现金在 `T` 支付，再乘 `e^{-rT}`。  
实务还要问：

- 是否有**名义本金**（notional）缩放？  
- 收益是「收益率」还是「绝对点数」？  
- 是否有**最低赎回 / 保本比例**（floor）？  

本库鲨鱼鳍向上敲出结构里的 `floor_return`、`participate_rate` 就是这类条款参数——**不是纯期权公式里的 K**。

## 7. 课堂题 vs 实务题：对照一张表

| 课堂 | 实务额外要答 |
|------|----------------|
| 给 σ、r、q | σ 用历史还是隐含？曲面哪一档？ |
| 连续障碍 | 日终观察还是连续？是否有观察窗口？ |
| 单一标的 | 篮子？最差表现？敲入看谁？ |
| 无交易费用 | 对冲成本、买卖价差、涨跌停 |
| 立刻成交 | 报价时效、审批、额度、适当性 |
