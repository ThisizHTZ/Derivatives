# 06 · 蒙特卡洛与数值方法

MC 不是「路径越多越高级」，而是：**偏差（bias）和方差（variance）都要管**。

## 1. 几何布朗运动回顾

本库 `geo_brownian_motion`：

```text
S_{t+Δt} = S_t * exp((b - ½σ²)Δt + σ√Δt * Z),  Z ~ N(0,1)
```

这是风险中性下的欧拉–丸山精确解（GBM 有闭式），适合欧式与许多路径依赖。

## 2. 三个旋钮

| 参数 | 影响 | 经验 |
|------|------|------|
| `paths` | 方差 ~ 1/√N | 研究 1e4–1e5；报告级更高 |
| `steps` | 离散监控偏差 | 日终观察 ≈ 交易日数 |
| `seed` | 可复现性 | 对比实验必须固定 |

```python
from derivatives import european_call_mc, shark_fin_option

european_call_mc(steps=252, paths=100_000, T=1, S0=100, K=99, sigma=0.2, r=0.03, b=0.03, seed=42)
```

## 3. 何时 MC 结果「看起来像对的」

1. 与 BSM 交叉验证（欧式香草）相对误差进入可接受带（如 1–2%）  
2. 加倍路径，价格变化小于你的报价精度  
3. 固定 seed，只改一个参数，曲线平滑  

若改 `seed` 价格跳 10%，说明方差太大，先加路径，别急着改模型。

## 4. 障碍与离散监控

连续障碍解析解假设「任何瞬间触及都算」。  
多数国内 OTC：**交易日收盘价**观察。

后果：

- 同样 H，离散监控的敲出概率更低（路径可能盘中穿障、收盘回来）  
- 价格系统性地不同于连续公式  

本库鲨鱼鳍 MC 按步长监控 `max(prices)`，步长≈日频时更接近日终；步长很少则更粗。

## 5. 方差削减（进阶，课程可能只提名字）

| 方法 | 想法 | 适用 |
|------|------|------|
| 对偶变量 | 用 Z 与 -Z | 欧式等较对称 payoff |
| 控制变量 | 用可知定期望的香草作对照 | 结构化 ≈ 香草 + 残余 |
| 公共随机数 | 估 Greeks / 情景差 | bump 敏感度 |
| 拟随机数 | Sobol 等 | 平滑 payoff，障碍需小心 |

当前库为清晰起见使用朴素 MC；生产库会组合以上技术。

## 6. 二叉树要点

- CRR：`u = e^{σ√Δt}`, `d=1/u`  
- 欧式可只存终端一列倒推；美式每节点比内在价值  
- 步数太少会在障碍附近振荡  

对照练习：

```python
from derivatives import black_scholes_merton, european_call_tree
bs = black_scholes_merton(100, 100, 1, 0.05, 0.2, "call")
tr = european_call_tree(100, 100, 0.05, 0.2, 1, steps=500)
```

## 7. 性能小建议

- 向量化路径生成比 Python 双层循环快一个数量级以上（生产应重构）  
- `numba` 对美式树有帮助；先保证正确再加速  
- 不要在未固定 seed 的情况下「优化到某个目标价」——那是在拟合噪声  

## 8. 实验作业

1. paths = 1e3, 1e4, 1e5，画 MC 价格与 BSM 的误差条。  
2. 障碍 MC：steps = 50 vs 252，比较敲出频率。  
3. 用同一组随机数，对 S 做 ±1% bump，估数值 Delta。
