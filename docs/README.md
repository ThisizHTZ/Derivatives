# 衍生品定价实务手册

本手册面向**课程之外**的定价、对冲与结构化产品落地：不只讲公式，更讲参数怎么取、条款怎么读、模型哪里会翻车、交易台日常怎么用。

适合：已学过 BSM / 二叉树 / 蒙特卡洛的同学，想把代码接到真实产品与市场数据上。
